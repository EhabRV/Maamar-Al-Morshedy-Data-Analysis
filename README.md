# Maamar Al Morshedy | Real Estate Data Analysis

## Project Overview

An interactive Power BI report analyzing collection and payment information across **eight real estate projects** associated with Maamar Al Morshedy. The report brings the projects together in one place, with shared summary pages and dedicated pages for each project.

A major part of the work was **extensive data cleaning and transformation using Power Query**, preparing the source data for analysis and reporting.

## Objectives

- Clean and prepare messy source data for analysis.
- Consolidate eight real estate projects into one Power BI report.
- Present an overall summary of the projects and collection data.
- Provide project-level views to explore collection through different payment types.

## Tools & Technologies

- **Power BI** — report development and interactive data visualization
- **Power Query** — data cleaning and transformation

## Data Preparation

The source data required substantial cleaning before it could be used in the report. Power Query was used to clean and transform the data as part of the preparation process.

## Report Structure

The report contains **35 pages**: three general pages and four pages for each of the eight projects.

### General Pages

- Home
- Global Summary
- Collection

### Projects Covered

1. One Kattamya
2. Zahra
3. Crystal Plaza
4. Degla Landmark
5. Skyline Kattamya
6. Degla Palms
7. Lake Front
8. Rihana

Each project includes four report pages:

- **Overall**
- **Bank**
- **Cash**
- **Bank - Wise**
